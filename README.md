# Лабораторная работа №1 «Знакомство с Python»

## Запуск решения

В терминале из папки проекта выполните `python3 main.py`.
Дополнительные библиотеки устанавливать не нужно.

Пример ввода: путь `sample_csv/two_liner.csv`, номер региона `1` (Night City),
ID колонки `3` (npg). Нумерация колонок начинается с 1 и выводится программой.
Регионы выводятся без повторов в порядке появления в файле, с номерами от 1.
Для выбора региона нужно ввести его номер из списка.
Для этого примера минимум — 1.9, максимум — 2.8, медиана и среднее — 2.35.

Файл должен быть в кодировке UTF-8, с запятыми в качестве разделителей,
заголовками в первой строке и колонкой `region`. Дробная часть чисел
отделяется точкой. Пустые и нечисловые значения выбранной колонки
считаются ошибкой; они не пропускаются при вычислениях.
Для выхода в любой момент нажмите Ctrl+C.

В `file_io.py` находится чтение CSV, в `logic.py` — фильтрация и расчёты,
в `main.py` — ввод и вывод. Используется только стандартный модуль `csv`
и базовые средства Python; статистика вычисляется без библиотек.

Перцентили вычисляются линейной интерполяцией: в отсортированном списке
позиция равна `(количество - 1) * процент / 100`. Для дробной позиции
берётся промежуточное значение между соседними числами.
Медиана равна 50-му перцентилю.

## Задание

Разработать на Python (версии 3) программу для вычисления статистических метрик набора данных.

### Входные данные

- CSV-файл с данными (`russian demographic.csv`). Путь до файла должен указать пользователь.
- Название региона.
- ID колонки, по которой будут найдены статистические метрики.

### Выходные данные (результат)

- Таблица значений по конкретному региону, визуализированная в консоли (выводить все колонки).
- Максимум, минимум, медиана, среднее значение по данным из выбранной колонки, выведенные в текстовых полях.
- Таблица перцентилей от 0 до 100 с шагом 5.

**N-й перцентиль** — это такое число X, что N% элементов массива меньше или равны этому числу X.

Необходимо по выбранной пользователем колонке, с учетом фильтра по региону вывести:

- Таблицу значений по региону, визуализированную в консоли.
- Максимум, минимум, медиану, среднее значение по данным из выбранной колонки, выведенные в текстовых полях.
- Таблицу перцентилей от 0 до 100 с шагом 5.

Программа должна корректно обрабатывать все виды ошибок и уведомлять об этом пользователя (некорректный входной файл, ошибки данных и т. п.).

Программа может иметь консольный или десктопный интерфейс.

## Общие требования к лабораторным работам

- Следовать принципам KISS, DRY, YAGNI и т. п.
- Код приложения, если это не Jupyter Notebook, должен быть разделен на «слои» / компоненты, как минимум:
  - **Компонент логики** — отвечает за логику приложения, содержит доменные модели, классы, позволяющие с ними взаимодействовать и реализующие основную задачу, поставленную перед приложением. Должен быть независим от конкретной реализации других компонентов. Не должен содержать логику ввода-вывода.
  - **Компоненты ввода/вывода** — отвечают за ввод данных пользователем, чтение и запись данных в файл и т. п. Не должны содержать логики обработки данных, только чтение, парсинг и форматированный вывод.
- Приложение должно корректно обрабатывать ошибочный ввод пользователя, ситуации отсутствия необходимого файла, некорректных данных и т. п., выводя понятную пользователю ошибку, а не завершая работу аварийно.
- Код должен соответствовать code style соответствующего языка: для Python.
